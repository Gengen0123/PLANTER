# 要件定義

## 1. 概要
観葉植物の育成を趣味とするユーザーが、自分の育てている植物とその成長過程を記録し、オリジナルの植物図鑑として管理・共有できるWebアプリケーションを開発する。  
ユーザー自身の育成記録を残すだけでなく、公開された図鑑を通じて、観葉植物に関する知識交換やコミュニケーションが生まれることを目指す。

## 2. 対象ユーザー
* 観葉植物を育てている人
* 植物の成長を写真で記録したい人
* 育てている植物をSNSなどで共有したい人
* 他のユーザーの育成方法や成長記録を参考にしたい人

## 4. 用語の定義
### 植物
ユーザーが育てている植物の1個体。
同じ品種であっても別の鉢や別の個体であれば、それぞれ別の植物として登録する。

### 成長記録
登録した植物に対して追加する、写真・記録日・育成メモからなる投稿を指す。

### マイ図鑑
ユーザーが登録した植物を一覧表示するページを指す。

## 5. 機能要件
### 5.1 ユーザー機能
* アカウントを作成
* ログイン/ログアウトできる
* マイページを表示できる
* ログインしていないユーザーは、植物や成長記録を登録・編集・削除できない

### 5.2 植物管理機能
ユーザーは、育てている植物をマイ図鑑に登録できる。  
植物には、以下の情報を登録する。

* 植物名
* 品種名
* 画像
* 説明
* 登録日時

ユーザーは、自分が登録した植物を編集・削除できる。
他のユーザーが登録した植物は編集・削除できない。

### 5.3 成長記録機能
ユーザーは、登録した植物に成長記録を追加できる。
成長記録には、以下の情報を登録する。

* 写真
* 記録日
* 育成メモ
* 投稿日時

植物の詳細画面では、過去の成長記録を新しい順または古い順に表示し、植物の成長過程を確認できる。
ユーザーは、自分が投稿した成長記録を編集・削除できる。

### 5.4 マイ図鑑機能
マイ図鑑には、ユーザーが登録した植物をカード形式で一覧表示する。  
図鑑カードには、以下の情報を表示する。

* 画像
* 植物名
* 品種名
* 最新の記録日

図鑑カードを選択すると、植物の詳細画面へ移動する。

### 5.5 図鑑共有機能
ユーザーごとに、マイ図鑑を閲覧できる共有用URLを発行する。
共有用URLを知っているユーザーは、ログインしていなくても図鑑を閲覧できる。
閲覧者は、共有された図鑑の植物や成長記録を編集・削除できない。

### 5.6 バリデーション
以下の場合は、登録を受け付けず、エラーメッセージを表示する。

* 必須項目が入力されていない
* 対応していない形式の画像が選択されている
* 入力文字数の上限を超えている

* PCおよびスマートフォンで利用できる

* ユーザー本人以外は、マイ図鑑をはじめとする登録情報を編集・削除できない
* 操作結果や入力エラーをユーザーに分かりやすく表示する
